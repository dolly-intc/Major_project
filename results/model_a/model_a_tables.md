## Table A2. Input features (computed from each core type's own counters)

Top-down shares (retiring, fe_bound, be_bound, bad_spec) are divided by the sum of that core type's four top-down counters, so they add up to 100%.

| Feature | Meaning | P-core counters | E-core counters |
|---|---|---|---|
| `ipc` | Instructions completed per clock cycle | INST_RETIRED.ANY / CPU_CLK_UNHALTED.THREAD | same |
| `retiring` | Share of work slots doing useful work | UOPS_RETIRED.SLOTS | TOPDOWN_RETIRING.ALL_P |
| `fe_bound` | Share of slots lost waiting for instructions (fetch/decode) | IDQ_BUBBLES.CORE | TOPDOWN_FE_BOUND.ALL_P |
| `be_bound` | Share of slots lost waiting on execution units or data | TOPDOWN.BACKEND_BOUND_SLOTS | TOPDOWN_BE_BOUND.ALL_P |
| `bad_spec` | Share of slots wasted on wrongly guessed (speculative) work | TOPDOWN.BR_MISPREDICT_SLOTS | TOPDOWN_BAD_SPECULATION.ALL_P |
| `mem_stall_frac` | Share of cycles stalled waiting for data from L2, L3 or main memory | MEMORY_STALLS.L2 + MEMORY_STALLS.L3 + MEMORY_STALLS.MEM | MEM_BOUND_STALLS_LOAD.ALL |
| `dram_stall_frac` | Share of cycles stalled waiting for main memory (DRAM) | MEMORY_STALLS.MEM | MEM_BOUND_STALLS_LOAD.LLC_MISS |
| `branch_mispredict_rate` | Share of branches guessed wrong | BR_MISP_RETIRED / BR_INST_RETIRED | same |
