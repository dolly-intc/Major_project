# results/ — thesis output

Figures, tables, and evaluation output intended for the thesis and the final presentation.

Everything here is **generated** by a script in `analysis/`, never hand-edited, so any figure
can be regenerated after a data correction or a model retrain. If a number in the thesis cannot
be traced back to a script in `analysis/` reading a file in `data/raw/`, it does not belong here.

Report medians with confidence intervals across repeated runs, interpreted against the noise
floor measured in Stage 1 week 3. A difference smaller than the machine's own run-to-run spread
is not a result.
